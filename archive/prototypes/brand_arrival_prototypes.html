❓ Spreadsheet Column Question

Does this require adding another column in Google Sheets?

No new column is required! Your existing schema in CronCode.gs already has:

• Col 3 (Code): "PENDING" vs "THYRO-9823-1102"
• Col 9 (Status): "PENDING" vs "ACTIVE"
• Col 10 (Timestamp): Populated with exact delivery time IST

A voucher is legally spendable if and only if code !== 'PENDING' && status === 'ACTIVE'. The frontend simply uses this existing check!

🔄 2-Stage Lifecycle Separation

How the Lifecycle Flows

STAGE 1: Acknowledgement Email Activity Log Only

Voucher code is not yet generated. Confined strictly to Activity Log with a soft red tint & red left stripe. Hidden from brand tab carousel to avoid polluting the count & math.

STAGE 2: Delivery Email Arrives Brand Tab + Blue Stripe

Real voucher code arrives. The voucher is unlocked in its respective brand tab, with a vibrant Blue "NEW" status accent stripe. Cumulative Denomination updates cleanly!
